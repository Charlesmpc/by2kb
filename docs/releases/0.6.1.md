# 0.6.1 — YouTube works with default configuration

Fixes #45: submitting a YouTube URL could fail with
`no configured source provider supports` even when yt-dlp was installed. Missing
source configuration previously selected Bilibili only, before any download or ASR.

## Changes

- Both Bilibili and YouTube now have default routes in runtime configuration,
  interactive initialization, and the agent-local preset.
- yt-dlp ships with the base package; existing `youtube` and `source-ytdlp` extras
  remain compatible. Browser support is still optional.
- YouTube uses available captions first, then audio with the user's configured
  ASR. No separate source selection is needed for the default workflow.
- Routing errors explain configuration overrides; missing-dependency errors explain
  installation repair. Doctor reports explicitly disabled yt-dlp without asking
  users to install unused dependencies.

## Upgrade without resetting configuration

```bash
pipx upgrade by2kb
# Or, if installed with uv:
uv tool upgrade by2kb
by2kb version
by2kb doctor --json
```

No config migration writes are performed. Missing `sources.providers` inherits
both defaults, including existing configurations with only browser fallback options.
ASR, credentials, model choices, browser settings and knowledge-base paths are preserved.

Explicit provider lists and `BY2KB_SOURCE_PROVIDERS` overrides keep their existing
meaning and order. An older explicit Bilibili-only list is indistinguishable from
an intentional restriction: to adopt both defaults, remove just that list override
or change it to `["bilibili_native", "yt_dlp"]`. An explicit
`[sources.yt_dlp] enabled = false` remains disabled. Do not run `init --force`.
See [upgrade compatibility](../upgrading.md#bilibili-and-youtube-defaults).

## Hermes

by2kb is now listed in the Hermes Catalog. This release does not change the plugin
hook or CLI protocol; the 0.6.0 plugin can use the corrected 0.6.1 CLI. Updating
only the plugin does not upgrade the CLI. The 0.6.1 catalog pin is submitted as a
separate upstream PR; once accepted, catalog users can run
`hermes plugins update by2kb`. Do not overwrite catalog installs with the legacy
copy installer. Restart a running gateway only when ready to reload plugin code.

## Validation and limits

- Local Windows regression suite: 309 passed, 1 platform-dependent skip.
- Fix PR regression CI passed on Windows and Linux.
- Tests cover config preservation, explicit lists/environment overrides, disabled
  sources, default caption ingestion, and audio fallback to the selected ASR.
- Wheel metadata confirms yt-dlp is a base dependency and compatibility extras remain.

No new live YouTube/Telegram, cloud-ASR, browser or model-download test was performed.
This fixes source selection, not YouTube authentication, rate limits, or access
restrictions. No production gateway or user configuration was changed for this release.
