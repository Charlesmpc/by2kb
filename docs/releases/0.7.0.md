# 0.7.0 — Find learning videos, then keep the knowledge

Send `by2kb 我想了解一下 TiDB 向量检索` to Hermes to search for learning
videos. Receive up to 3–5 numbered candidates with links and recommendation evidence,
then reply `1` or `1,3` to enter the existing transcript, abstract and study-notes
workflow. Fewer results are returned when suitable matches are unavailable.

## Changes

- Independently configurable Bilibili and YouTube search providers, concurrent
  searches with deadlines, topic-word screening, and canonical-URL deduplication.
- Configurable `captions_only` previews (default) or `metadata_only`. Search never
  downloads audio/video or invokes ASR. Captions fetched for displayed candidates
  are cached and reused when selected; unavailable captions leave metadata previews.
- User/chat/thread-scoped recommendation sessions with expiry, cancellation,
  supersession, validated numeric selections and repeat-safe ingestion.
- Learning-topic context accompanies source provenance and grounded summary prompts.
- Hermes explicit `by2kb TOPIC` activation and a matching manual Agent Skill.

Search settings are separate from ingestion settings. Disable discovery globally,
enable only selected providers, or disable caption previews. See
[topic search configuration](../topic-search.md). Agent Reach inspired the discovery
and tool-routing design; no Agent Reach code or runtime dependency is included.

## Upgrade

```bash
pipx upgrade by2kb
# Or: uv tool upgrade by2kb
by2kb version
by2kb doctor --json
hermes plugins update by2kb
```

Upgrade the CLI and plugin independently. The Hermes catalog update requires
upstream acceptance; until its 0.7.0 pin is accepted, a catalog update may still
install the prior plugin. Follow [agent deployment](../agent-integration.md) for
the existing Git installation path. Reload a running gateway to use updated code.
Existing configuration is preserved; missing search settings inherit defaults.

## Validation and limits

Local regression tests cover discovery, preview cost boundaries, cancellation,
scope isolation, cached-caption ingestion, learning context and Hermes routing.
A live search returned candidates from Bilibili and YouTube; accessible caption
previews were unavailable in that smoke run. No live gateway or paid ASR run was
performed. Recommendations use available metadata/captions, not a complete review
of every video's quality. Podcast and article ingestion remain future extensions.

OpenClaw/ClawHub Skill publication is not part of this release.
