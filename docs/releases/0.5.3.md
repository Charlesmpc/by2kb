# by2kb 0.5.3 — Small task tickets, complete transcript content

Agent tool output could be truncated when large claim/next responses were printed
into a terminal. This release separates control information from prompt content:

- `enrichment next --json` returns a small schema-2 operation ticket with an immutable
  request-file reference, checksum and input size. The full prompt remains on disk.
- `enrichment read` pages system/user prompts with explicit offsets and EOF. The
  bundled Hermes adapter verifies and loads the file directly, without model-mediated
  copying of operation IDs. Do not concatenate claim and next output.
- Oversized ASR segments are split losslessly within their original time range.
  Program-controlled chunk summaries and recursive reduction remain responsible for
  long-input processing, not an Agent guessing how much of the transcript to read.
- A 24,000 estimated-token Agent input guard rejects excessive prompts without
  silently truncating them. It is a heuristic safeguard, not a context guarantee for
  every host model. Request-file transport has a separate 32 MiB safety limit.
- Includes unpublished 0.5.2 fixes: idempotent submissions, local process locks,
  bounded resynchronization and completed-state/error-notification protection.

## Upgrade

After this version is available on PyPI:

```bash
pipx upgrade by2kb
by2kb agent install hermes --force
by2kb version
```

Restart the Hermes gateway after refreshing the plugin. Back up custom edits inside
the managed plugin directory before `--force`; it replaces that code copy. User
configuration, personalized Skills, checkpoints and knowledge-base files are not
automatically overwritten. Personalized Skills need the updated paging instructions
applied explicitly. Pinned Git installations must first switch to a PyPI source if
they are intended to follow PyPI upgrades.

Custom CLI adapters must support the new file ticket, or request `--inline-prompts`
for legacy output. Python service APIs remain inline-compatible. Request files must
be accessible to the Agent and may contain private transcript text. See the
[Agent protocol](../agent-enrichment-provider.md) for paging and submission rules.
Pipeline 1.1 invalidates reuse of older intermediate cache keys without deleting
their files; in-progress jobs may regenerate intermediate notes after upgrading.

## Validation scope

Deterministic tests cover a million-character request, million-character single-
segment lossless planning, Unicode page reassembly, tamper detection, oversized-input
rejection and a complete file-backed staged CLI flow with intermediate summaries.
Linux/Windows CI exercises the full suite. No paid ASR/LLM call or live Telegram
production replay is implied by these tests.
