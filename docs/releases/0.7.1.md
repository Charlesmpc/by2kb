# 0.7.1 — Clearer learning-video recommendations

Separated entries prominently label YouTube/Bilibili, show precise durations,
and retain public view/like counts when returned by the platform. Missing metrics
are omitted; a genuine zero is displayed. Repeated caption-preview failures and
partial-source warnings no longer clutter successful recommendation messages.
Preview status and provider warnings remain available in structured JSON.

YouTube search/detail metadata and Bilibili search/view metadata supply available
public metrics. Popularity does not change relevance ranking. Existing sessions
remain readable; optional fields need no migration. Configuration, credentials,
ASR, browser settings and knowledge-library paths are preserved.

Search still downloads no audio/video and never invokes ASR. This release does
not add browser-session fallback or resolve YouTube robot/login challenges.
A searchable candidate is not proof that selected-video ingestion can complete.

## Upgrade

Upgrade the installed CLI with `pipx upgrade by2kb`. Legacy copy plugin installs
can use `by2kb agent install hermes --force`; catalog/Git-owned plugins must use
their original owner. Reload a running gateway after updating plugin code.
Verify the resulting configuration with `by2kb doctor --json`.
